## 2024-06-10 - Accessibility Labels in Pure SwiftUI Apps
**Learning:** In pure SwiftUI apps, icon-only buttons often lack accessibility context for VoiceOver. Elements like `Image(systemName: "plus")` inside a `Button` will not read aloud a descriptive action natively without being explicitly told. Conditional accessibility text, such as `.accessibilityLabel(isOpen ? "Close Menu" : "Open Menu")` or `.accessibilityLabel(task.imageData == nil ? "Attach Image" : "Change Image")` provides powerful, dynamic context to users based on state changes.
**Action:** Always add `.accessibilityLabel("Descriptive Text")` modifiers to custom components, floating action buttons, and any button lacking text labels. If the button has states (e.g., toggles), pass conditional string variables to the modifier to keep VoiceOver synchronized with the UI state.
